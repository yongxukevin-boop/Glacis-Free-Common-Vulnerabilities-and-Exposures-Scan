UNDERSTAND THE CHECK

What is a URL CVE scan?

A URL CVE scan is a digital safety check that looks at a web link for signs of known security flaws in the software behind it. These flaws are catalogued as Common Vulnerabilities and Exposures (CVEs).

This scan can also flag other template-matched security issues. Each finding is a starting point for investigation: automated checks do not fix vulnerabilities or replace a full penetration test.

A FEW THINGS TO KNOW

Your questions, answered.

Is the scan free?

Glacis does not charge a scan fee. This version requires a GitHub repository access token. GitHub Actions usage limits and any charges apply to the repository owner. Email signup is optional.

What will the scan check?

It checks known exploited vulnerabilities and informational templates, including configuration and service observations. Informational findings are not confirmed CVEs. Coverage depends on the available templates and target. It is not a malware certification, exhaustive security audit or guarantee of OWASP compliance.

How long does a scan take?

Allow time for GitHub to queue the job, install Nuclei and run its checks. The scanner has a 20-minute execution limit. The dashboard displays the workflow’s actual status.

Are my results private?

No. This deployment commits findings, target URLs and HTTP snippets to a public GitHub repository. Only scan targets whose results you are authorised to publish. Marketing email addresses are never included in those reports.

Does an empty report mean my site is secure?

No. It means no vulnerabilities matched the selected checks. Findings require verification, and security issues can exist outside the scan’s coverage.

Do I need to share my email?

No. Signup is separate from scanning. If you opt in, your email is used for Glacis security updates and service offers, not to unlock a report.
