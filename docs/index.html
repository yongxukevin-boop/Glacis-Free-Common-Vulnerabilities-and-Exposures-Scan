What does a URL CVE scan do?

A URL CVE scan is a digital safety check that looks at a web link (URL) for signs that the software running behind it has known security flaws. These flaws are catalogued as Common Vulnerabilities and Exposures (CVEs).

When you start a scan, Nuclei sends test requests to the target website and compares its responses with vulnerability checks called templates. It can flag potential CVEs and other security issues, then group the findings by severity so you can decide what to investigate first.

The report shows affected endpoints, available evidence and remediation guidance when provided by the template. Findings need verification: the scan does not fix issues, and an empty report does not guarantee that a website is secure.
